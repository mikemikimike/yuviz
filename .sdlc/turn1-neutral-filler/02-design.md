# Design: Neutral turn-1 filler (issue 136)

## Approach
Each language module gains an optional `FIRST_TURN_FILLERS` table with exactly the `TOOL_FILLERS` shape `((phrase, seconds), ...)`, validated by the same predicate at import. `FillerSelector` gets a sibling method `select_first_turn_filler` that runs today's tier rule (largest tier at or below target, else shortest; avoid the last phrase) over that pool, so #98's latency sizing and the 1.6s default carry over unchanged. The tier rule is lifted out of `select_tool_filler` into one private helper that both methods call, so turn 2+ behaviour cannot drift. A language module without the table gets its own `shortest_tool_filler` and never the English pool. This beats the obvious alternative, rewording `TOOL_FILLERS` to sound neutral: that would change turn 2+ (out of scope), and lookup wording is the right wording mid-task. Every tool-call filler on any turn, including turn 1's tool call, keeps coming from `TOOL_FILLERS`; only the pre-LLM turn-1 opener uses the neutral pool (AC10). `select_tool_filler` and its `ToolCallStartedEvent` call site are not touched.

## Data
None.

## Interfaces
- `i18n.first_turn_fillers(language: str | None) -> tuple[tuple[str, float], ...] | None`: the normalized language's own `FIRST_TURN_FILLERS`, else `None`. A language with a module but no table returns `None`, never en's pool (AC7). An unknown language with no module resolves to the `en` table, as `t`/`tool_fillers` do today.
- `i18n.shortest_first_turn_filler(language: str | None) -> str`: `_SHORTEST_FIRST_TURN.get(normalize_language(language) or "en", _SHORTEST_FIRST_TURN["en"])`.
- `FillerSelector.select_first_turn_filler(self, last_phrase: str | None, average_ms: float | None, language: str | None = None) -> str`: never returns None and never raises.
- `fillers._pick(pool: tuple[tuple[str, float], ...], last_phrase: str | None, average_ms: float | None) -> str`: private, and raises like today's body does. Each caller owns its own `except`.
- Out of scope (AC7): a language registered in the language registry but with no i18n module keeps today's English fallback (`_SHORTEST['en']`, `i18n/__init__.py:103`); `first_turn_fillers` resolves it to en's pool and the error path to `_SHORTEST_FIRST_TURN['en']`. Only a language that has a module without the table gets its own shortest tool filler.
- Constant name: `FIRST_TURN_FILLERS`, matching the pipeline's existing `first_turn_filler*` naming.

## Risks
- Phrase naturalness is a judgment call (AC3 needs a reviewer sign-off). Mitigation: phrases are listed verbatim above for the PRD reviewer and a native Hindi reader. The stem test catches only lookup wording, not awkwardness.
- Banned-stem lists can be satisfied vacuously. Mitigation: the test asserts each pool is non-empty and that every `TOOL_FILLERS` phrase containing a banned stem would be caught (en "Let me check on that.", hi "जी, अभी देखते हैं।"), so the matcher is proven able to fire (lesson 12).
- Extracting `_pick` could alter turn 2+ selection. Mitigation: it is a pure move. `test_fillers.py` and the turn-2+ pipeline tests, except the rewritten turn-1-vs-tool-filler test, run unchanged as the regression gate (AC10).
- The raise-path test monkeypatches `fillers.random.choice`, which now runs inside `_pick`. Mitigation: `_pick` still calls `random.choice` from the same module, so the patch still applies, and the test asserts exactly one ERROR record from `services.conversation.fillers`.
- A future language could declare a turn-1 pool whose shortest tier is above 1.0s, so fast agents hit the "shortest" fallback in `_pick`. That still speaks a phrase (no empty selection). Mitigation: the docs ask for a phrase at or below the shortest tool-filler seconds, and the AC12 test enforces it for en/hi.

## Test plan
Unit tests in `test_i18n.py`/`test_fillers.py`, integration tests through `on_speech_ended` in `test_pipeline.py`. All use the deployed tables and `_DEFAULT_TARGET_S`.
1. Default tier, en and hi (pipeline, no store and empty store). The spoken turn-1 phrase is in the `FIRST_TURN_FILLERS` tier `max(s <= _DEFAULT_TARGET_S)`. It is `not in` that language's `TOOL_FILLERS` phrases. Exactly one turn-1 phrase is spoken. Fails today, because today it speaks "Let me check on that.".
2. Latency tiers (pipeline, agents seeded at 1000 ms and 2400 ms). Fast is in the 1.0 tier, slow is in the 2.4 tier, and the slow phrase's seconds are >= the fast phrase's seconds. Turn 2+ tool-call tier tests run unchanged. With a turn-1 tool call at 2400 ms, exactly one phrase from `_FIRST_TURN_FILLERS` and exactly one from `_TOOL_CALL_FILLERS` are spoken, turn-1 first (rewritten 2502-2528 test).
3. Selector raises (pipeline, `random.choice` patched; en and hi). The spoken phrase `== shortest_first_turn_filler(lang)` and is `not in` `TOOL_FILLERS`. For hi it is in `hi.FIRST_TURN_FILLERS`. There is exactly one ERROR log record.
4. Import contract (`_discover` on a tmp package). An `xx` module with `FIRST_TURN_FILLERS` set to `()`, `[("a", 1.0)]`, `(("", 1.0),)`, `((1, 1.0),)`, `(("a", 0),)`, `(("a", float("inf")),)`, `(("a", True),)` or `(("a", 1.0, 2),)` raises `ValueError` matching both `'xx'` and `FIRST_TURN_FILLERS`. An `xx` module without the table discovers fine. With `_TABLES`/`_SHORTEST_FIRST_TURN` patched as in the existing wiring test at `test_i18n.py:133`, `select_first_turn_filler(None, 1000, "xx")` returns `xx`'s shortest `TOOL_FILLERS` phrase and nothing from `en`.
5. Content (`test_i18n.py`). The en and hi pools contain no banned stem: en `check`, `look into`, `take care of`; hi `देख`, `पूरा कर`. Each matcher is shown to fire on the matching `TOOL_FILLERS` phrase. Each pool is disjoint from its `TOOL_FILLERS`. Each pool's `min(seconds) <= min(TOOL_FILLERS seconds)` (AC12). No hi phrase contains Latin letters.
